# 关于这个博客

Kyro Blog 是一个长期维护的个人博客，用来整理开发过程、学习笔记和项目复盘。

这个站点的技术栈很简单：

- Hugo 负责生成静态站点
- LofiCode 负责页面主题
- GitHub Pages 负责自动部署

我希望把这里做成一个可以持续积累的知识仓库，而不是一次性页面。

## 关于我

这里更像是一份长期维护的个人技术档案。我会把平时折腾过、踩过坑、最后真正跑通的东西沉淀下来，方便以后自己回看，也希望能给路过的读者省一点试错时间。

目前会比较多地记录这些方向：

- 实战项目搭建过程
- 开发中的问题定位与修复
- 工具链和效率优化
- 学习路线的复盘

如果某篇文章看起来像“从零到能跑通”的操作手册，那通常就是我在真实环境里一步步验证过后整理出来的版本。
