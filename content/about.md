# 关于这个博客

Kyro Blog 是一个长期维护的个人博客，用来整理开发过程、学习笔记和项目复盘。

这个站点的技术栈很简单：

- Hugo 负责生成静态站点
- LofiCode 负责页面主题
- GitHub Pages 负责自动部署

我希望把这里做成一个可以持续积累的知识仓库，而不是一次性页面。

## 关于我

我会把日常开发里值得记录的内容放在这里，包括：

- 实战项目搭建过程
- 开发中的问题定位与修复
- 工具链和效率优化
- 学习路线的复盘
